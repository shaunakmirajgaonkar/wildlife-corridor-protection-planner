# Wildlife Corridor Protection Planner — CorridorGuard Local

A privacy-conscious, local-first Streamlit workspace for screening wildlife corridor threats from roads, construction, light pollution, land-use change, human encroachment, crossing pressure and protection coverage.

## Features
- Explainable 0–100 corridor risk score
- Low / Moderate / High / Very High classification
- Local corridor risk mapping
- Threat analytics and evidence trends
- Habitat × risk analysis
- Priority corridor review queue
- Land-use change analysis
- Conservation Scenario Lab
- CSV upload and scored-data export
- No external APIs
- Synthetic sample data included for testing
